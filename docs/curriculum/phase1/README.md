# Phase1: Java基礎の補強（オブジェクト・クラス設計）

## このフォルダの目的
- Java初心者が、Day5のSpringアプリを読む前に必要な「クラス設計の土台」を作る。
- 1つずつ理解しながら進めるため、各回を独立した教材にする。

## 学習順
1. `lesson1.md` を実施（クラス・オブジェクト・フィールド・メソッド）
2. Lesson1の理解チェックに合格してから次回へ進む

## 学習ルール
- 用語は必ず日本語で言い換えて説明できるようにする
- コードは「1行ずつ意味を確認 -> 実行結果を予測 -> 実行」の順で進める
- わからない箇所は「何が」「どこで」「なぜわからないか」をメモする

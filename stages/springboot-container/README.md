# コンテナ化ハンズオン用アプリ

このフォルダには、実装済みの勤怠管理Spring Bootアプリがあります。
Javaアプリを一から作るのではなく、この完成済みアプリをDockerで動かすことがハンズオンの目的です。

最初の状態には、次のコンテナ関連ファイルはありません。

- `Dockerfile`
- `.dockerignore`
- `docker-compose.yml`
- `.env`

講義では、これらのファイルを順番に作成します。

手順は[Spring Bootコンテナ化コース](../../docs/curriculum/springboot-container/README.md)を参照してください。

## アプリの主な機能

- ログインとログアウト
- 出勤と退勤
- 本人の勤怠履歴
- 管理者によるユーザー管理
- 管理者による勤怠管理
- REST API
- MariaDB接続とFlywayによるテーブル作成

## 注意

- `src/main`は完成済みです。教材で指定された表示メッセージの変更以外は編集しません。
- パスワードなどの設定値は、ハンズオン中に作成する`.env`へ記載します。
- `.env`はGitへ登録しません。
